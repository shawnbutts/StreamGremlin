## Slice 1: hardening

Built 2026-11-15 (D-111, [ADR-0050](../adr/0050-security-and-load-testing.md)). There's no screen: nothing here is for a streamer to use.

- `TestEveryRouteIsGuarded` in `make verify`.
- `make test-fuzz`: 12 fuzz targets. Their saved failures run in `make test`.
- `make test-load`: the chat surge, with budgets. Baseline on the user's Mac: 45 runs a second, every run done in 44 s, API p99 72 ms, 64 MB.
- `make vuln`: govulncheck and npm audit.
- `SECURITY.md`.

### Check for slice 1 (user)

No live check is needed: nothing changed in what the app shows. The engine changes are the larger chat read-ahead and quieter redeliveries, which the next real stream covers. Before the wider beta, create `security@streamgremlin.com` (D-005), which `SECURITY.md` names.

## Slice 4: the website

Built 2026-11-15 (D-112), ahead of slice 2 at the user's request. `make site` builds `bin/site/www` for streamgremlin.com and `bin/site/code` for code.streamgremlin.com. `make screenshots` takes the pictures again, with made-up data.

### Check for slice 4 (user)

1. `make site`, then open `bin/site/www/index.html` in a browser. Read the home page and the comparison table: is the tone right, and is anything about the other bots wrong or unfair?
2. Open Help: each screen's text with its picture. In the app, Help (Ctrl/⌘ + /) shows the same text as before.
3. Open Download: it offers the newest installers in `bin/release` with their SHA-256.
4. Upload `bin/site/www` to streamgremlin.com and `bin/site/code` to code.streamgremlin.com. Serve `404.html` for missing pages. Then `go list -m code.streamgremlin.com/streamgremlin@latest` (or `curl 'https://code.streamgremlin.com/streamgremlin?go-get=1'`) shows the go-import tag.
