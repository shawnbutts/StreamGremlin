## Slice 1: hardening

Built 2026-11-15 (D-111, [ADR-0050](../adr/0050-security-and-load-testing.md)). There's no screen: nothing here is for a streamer to use.

- `TestEveryRouteIsGuarded` in `make verify`.
- `make test-fuzz`: 12 fuzz targets. Their saved failures run in `make test`.
- `make test-load`: the chat surge, with budgets. Baseline on the user's Mac: 45 runs a second, every run done in 44 s, API p99 72 ms, 64 MB.
- `make vuln`: govulncheck and npm audit.
- `SECURITY.md`.

### Check for slice 1 (user)

No live check is needed: nothing changed in what the app shows. The engine changes are the larger chat read-ahead and quieter redeliveries, which the next real stream covers. Before the wider beta, create `security@streamgremlin.com` (D-005), which `SECURITY.md` names.
