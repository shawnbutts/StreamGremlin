# M9: Release

The release work, ending in an unsigned wider beta (D-110): more testers than the user invites one by one, on Windows and macOS, with Linux lightly tested (D-003).

**Status:** decided 2026-11-15 (D-110).

M9 is done when the user has installed the wider beta's own installers on macOS and Windows, streamed with them, upgraded from the previous beta without losing data, and given Linux a smoke test, with the result written below.

## Slices

| # | Slice | State |
|---|---|---|
| 1 | Hardening: a sweep proving every API route needs the token, the right permission, a local `Host` and an allowed `Origin`; fuzz tests for every parser of outside input, each checking a property; a chat surge load test through the real binaries, with budgets; `SECURITY.md` | Next |
| 2 | Release builds for all three systems: a Linux package (.deb and .rpm, built in a container), reproducible archives, an SBOM for each binary, and checksums (StreamWisp's ADR-0050 and ADR-0052, rebuilt) | |
| 3 | Upgrade and install tests: a data folder from each earlier beta upgrades and keeps everything; the Linux package installs and starts in fresh containers; a checklist for the installers on the user's Mac and Windows machines | |
| 4 | The website: home, features, download, Help (one text for the app and the site), privacy, security and the changelog, built into a folder the user hosts | |
| 5 | The wider beta: the beta guide for testers the user hasn't met (where to report, what's unsigned and why), a release checklist, and the first wider beta build | |

## Left out

- **Code signing and notarization:** later (D-110).
- **Squashing migrations into one baseline:** at the first public release (ADR-0001).
- **Streamer.bot import:** after the release (D-061).
- **CI:** much later (D-007).
- **An OCI image:** there's no headless server (FEATURES.md).
- **Updating itself:** not in the feature cut. Testers download the next build.
