# M11: Your AI assistant

StreamGremlin 0.3.0: technical streamers connect their own AI assistant over MCP, to read their workflows and logs and to draft workflows that stay off until they turn them on (D-126).

**Status:** decided 2026-11-17 (D-126). Starts once M10 is done.

M11 is done when the user has paired an assistant on macOS and Windows, had it explain a real workflow run and draft a workflow that they then turned on and used on a real stream, and released 0.3.0 by [the release checklist](../RELEASE.md), with the result written below.

## Slices

| # | Slice | State |
|---|---|---|
| 1 | Read-only: `streamgremlin mcp`, the assistant as a paired client, the **AI assistant** card on Connections; reads workflows, triggers and steps, the event log without viewers' words, runs and errors, connections | |
| 2 | Workflow drafts: save a new or changed workflow turned off, checked by the engine, marked as from the assistant; the streamer's box for viewers' words | |
| 3 | 0.3.0: a help page on connecting Claude Desktop and Claude Code, the website's mention, and the release | |

## Left out

- **Live control:** scenes, ads, chat, moderation, points and winners (D-126).
- **MCP over HTTP:** only standard input and output, started by the assistant.
- **AI inside StreamGremlin:** providers, keys and spending stay Leave (D-004).

## Before slice 1

- Check the current MCP specification and the official Go SDK; record the version, transport and any limits in a new ADR (a protocol and a security boundary).
- Read StreamWisp's ADRs for anything on assistants or outside control, and how ADR-0042's pairing extends to a second kind.
