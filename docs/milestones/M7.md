# M7: Live

A Live screen to run a stream from, moderating from chat, and a Stream Deck plugin (D-075). It comes before M6, YouTube.

M7 is done when the user has used it on a real stream on macOS and Windows, and the result is written below.

## Slices

| # | Slice | State |
|---|---|---|
| 1 | The Live screen: Twitch chat with sending, and buttons that run workflows through a new "You press a button" trigger, down the right side or along the top | Planned |
| 2 | A viewer card on a chatter's name: Twitch's account, follow, subscription, VIP, moderator and banned; StreamGremlin's record, points and recent messages; asking for the scopes it needs | Planned |
| 3 | Moderating from chat: delete a message, time out, ban and unban, warn; shoutout, VIP, moderator; the chat modes. Each recorded, banning asks first | Planned |
| 4 | Stream Deck, part 1: how it pairs and what it may do ([ADR first](../../AGENTS.md), security); pairing on Connections | Planned |
| 5 | Stream Deck, part 2: the plugin, built with Elgato's SDK: press a button or run a workflow, show its state; packaged to install from a file | Planned |

Each slice checks Twitch's and Elgato's current docs first, and records the scopes, limits and anything uncertain in the capability manifest. Nothing outside their documented APIs is built.

## How it's meant to work

- **One place while live.** Chat fills the middle. The buttons the streamer made are beside it or above it, and pressing one runs the workflows it starts. Nothing needs another screen during a stream.
- **Buttons are a trigger.** "You press a button" names the button, so a Live screen button, a Stream Deck key and a workflow test all start the same workflows. A button has no viewer, so a step that needs one is refused, as with timers.
- **Unknown stays unknown.** A viewer card shows only what Twitch says or StreamGremlin recorded. A missing scope or a failed call says so, and doesn't guess.
- **Moderating is Twitch's.** StreamGremlin calls Twitch's documented endpoints as the streamer, or as the bot when it's a moderator and the streamer chooses that. It records each one, and says when Twitch refuses one and why.
- **The Stream Deck is another client.** Like the app and CLI, it reaches the engine through the authenticated local API. Its token is narrow: it can list and press buttons, run workflows and read their state, and nothing else. It's paired once on purpose, and can be removed.
