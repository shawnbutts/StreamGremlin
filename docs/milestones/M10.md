## Slice 1: Stream Deck keys

Built 2026-11-16 (D-123, D-124, [ADR-0053](../adr/0053-stream-deck-keys.md)). Seven new keys in the plugin beside **Press a button**: **Counter**, **Status** and **Switch**, then **Run a workflow**, **OBS scene**, **Countdown** and **Ad** (D-124, after the first check). In the app, Connections has **What your Stream Deck can use**: the counters and switches a deck may use, and what status keys show now.

- **Engine:** `internal/deck`; `GET /v1/deck`, `POST /v1/deck/counters/{name}`, `PUT /v1/deck/switches/{kind}/{id}`, `GET` and `PUT /v1/settings/streamdeck`. The deck's token gains `deck.read` and `deck.use`, which reach only what's chosen.
- **Tests:** the deck package (counting once per request id, never below 0, twenty presses at once, switches, the lock refused or unknown); the API (nothing until chosen, the deck can't choose); acceptance through the engine and the stand-in Twitch (a counter across a restart, a workflow switch, the chat lock once and recorded as from the deck); the plugin in a stand-in Stream Deck with the real engine (each key drawn, pressed and refused once un-chosen); the app's card.

### Check for slice 1 (user)

Install the new Stream Deck plugin (`bin/streamdeck/com.streamgremlin.streamdeck.streamDeckPlugin`, from `make streamdeck`) and the new app, on the Mac and the Windows PC. An already paired deck stays paired.

1. Connections → **What your Stream Deck can use**: add a counter (`deaths`), tick a workflow, a timer and the chat lock.
2. Drag **Counter** onto a key, pick `deaths` and "Adds one". Press it: the key and Variables both go up by one. A second key set to "Takes one" goes down, never below 0.
3. Drag **Status** onto four keys: live, chat, OBS, chat lock. Each shows on, off or "?", and changes within a few seconds of connecting OBS or going live.
4. Drag **Switch** onto keys for the workflow and the timer: a press turns it off (dim) and on (lit), and Workflows and Timers agree.
5. The chat lock switch: on a test, press it: chat locks on Twitch (Shield Mode, emote-only, followers-only), and Live's moderation history says "from your Stream Deck". Press again to unlock.
6. Un-tick the counter in the app: its key says "Choose in StreamGremlin", and pressing it changes nothing.

**Result (2026-11-16):** passed. The user: "tests looked good."

### Check for slice 1, part 2 (user)

The run, scene, countdown and ad keys (D-124). Install the new app and plugin again.

1. Connections → What your Stream Deck can use: tick a workflow under **Run a workflow** (a chat command one shows the warning), **Scene keys**, a countdown, and **ads**.
2. **Run a workflow** on a key: a press runs it (Workflows shows the run); with the workflow off, the key is dim and a press warns.
3. **OBS scene** keys for two scenes: the one on air is lit; a press switches. Switching in OBS itself moves the light within a few seconds.
4. **Countdown** on a key: it shows the time and counts each second while running; a press pauses and starts it; another key set to "Resets it" resets it. The overlay in OBS agrees.
5. **Ad** while live: it counts down to the next ad, with snoozes left; a press snoozes it (on Twitch's dashboard too). Not live or not signed in: "?".
