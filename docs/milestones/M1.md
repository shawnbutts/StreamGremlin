## Slice 1: skeleton

**Built:**
- `internal/datadir`, `internal/storage` ([ADR-0001](../adr/0001-storage.md));
- `internal/api`, `internal/host`, `internal/desktop` ([ADR-0002](../adr/0002-local-api.md));
- `cmd/streamgremlin`;
- `cmd/desktop` (Wails v3.0.0 + Svelte 5).

**Checked automatically (`make verify`):**
- **Go:** unit tests with the race detector, golangci-lint, and acceptance tests through the real `streamgremlin` binary:
  - CLI status, and status when nothing is running;
  - one engine per data folder;
  - token, Host and Origin checks;
  - settings surviving a crash and restart, with an unchanged token;
  - a clean stop removing `api-addr`;
  - the token never logged;
  - private file modes.
- **Desktop UI:** svelte-check, Vitest, axe checks in all three themes, and contrast checks of the brand tokens.
- **Desktop app:** vet, tests and build.
- The engine, CLI and desktop app cross-compile for Windows.

**Checked by hand on 2026-11-07 (macOS 26.6, by the agent):** the built desktop app started its engine on a scratch data folder, `streamgremlin status` reached it through the API, and quitting removed `api-addr` and released the lock.

**Platform capability notes:** none. This slice talks to no outside service.

**Migration notes:** creates the baseline schema (`settings`). Before the first public release, the baseline may be rewritten.

### Live check to do (user, macOS and Windows)

1. Build and open the app: `make desktop-ui desktop`, then `./bin/StreamGremlin`. On Windows, build `bin\StreamGremlin.exe` on the Windows machine.
2. **Home** says "Running", with a version, a "running for" time that counts up, and your data folder.
3. **Settings → Theme:** try each theme. The window changes at once. Quit, reopen: your choice is kept.
4. With the app open, run `./bin/streamgremlin status` in a terminal: it says it's running.
5. Open the app a second time: the first window comes forward, and no second copy starts.
6. Keyboard only: Tab through the sidebar and the theme choices, and use Ctrl/⌘+1 and Ctrl/⌘+2 to switch screens. Focus is always visible.
