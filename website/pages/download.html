The source code, the changelog and every issue are on GitHub. StreamGremlin is free and open source under the Apache License 2.0. GitHub builds each release from its tagged code.

The beta isn’t signed yet. Windows says “Windows protected your PC” and macOS says it can’t check the app for malicious software, because StreamGremlin doesn’t have a code-signing certificate yet. Linux packages aren’t signed either. The guide below says how to open it anyway. Only do that for a copy from StreamGremlin’s releases on GitHub, and check its SHA-256 if you can.
