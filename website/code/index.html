StreamGremlin’s code

StreamGremlin is free and open source under the Apache License 2.0. Its Go module is named {{.Module}}, so the name stays the same wherever the code is kept. Today it’s on GitHub.

The code on GitHub Documentation on pkg.go.dev

  • Get the code

    git clone {{.Repo}}

    CONTRIBUTING.md says what to install and how to build the app. make verify runs every check.

  • The command line

    go install {{.Module}}/cmd/streamgremlin@latest

    Needs Go {{.GoVersion}} or newer. It talks to the StreamGremlin app running on the same computer; the app itself comes from the download page.

  • Help make it better

    Report a bug or an idea in GitHub’s issues, and a security problem privately. Every commit is signed off under the Developer Certificate of Origin.
